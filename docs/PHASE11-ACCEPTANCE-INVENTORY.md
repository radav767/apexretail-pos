## Deferred list and boundaries

The finite required release backlog is the P0/P1 gate ledger in the limited contract. No optional row becomes a new release implementation project. Remaining programme work groups into: advanced saved pricing/split/recipes/payouts; full customization/selector adoption; dispatch/airtime; accounting/provider/email/fiscal commissioning; approved artwork; broader fonts/accessibility/hardware. Preserve their original policies and disabled capabilities.

Only cached Chromium/headless-shell1243 is available for browser acceptance here; Firefox/WebKit, native screen readers, installed-device and physical printer acceptance are unavailable/unperformed. Emulated forced colours, keyboard and large-text geometry are bounded software evidence, not native AT or universal WCAG certification. A new independent database/venv reduces fixture coupling but is still the same host/operator and does not substitute for independently controlled recovery-key custody or an off-host retrieval witness.
